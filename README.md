# Прокатный стан 300

**[Открыть 3D-модель](https://projectspeedup-commits.github.io/3D-stan/)**

Интерактивная схематичная модель оборудования прокатного стана. Каркас удалён. Заводская схема в репозитории и просмотрщике не публикуется.

## Управление

- Полные названия всех 62 узлов показаны прямо на модели. Подписи соединены с объектами линиями и не скрываются при отдалении. Девять окружающих объектов появляются вместе с «Территорией». Кнопка «Подписи» включает и выключает названия.
- Левая кнопка мыши — вращение, колесо — масштаб, правая кнопка — сдвиг.
- Нажмите на оборудование или выберите его в списке слева для описания и приближения.
- Кнопки внизу переключают участки: нагрев, ТРИО, промежуточные и чистовые клети, охлаждение, отделка.
- «Сверху» и «Сбоку» — готовые ракурсы; «Территория» — окружающие объекты.
- На телефоне: один палец — вращение, два — масштаб и сдвиг.

## Автономная версия

Скачайте `index.html` и откройте в Chrome или Edge. Интернет и установка программ не требуются.

[Отдельный 3D-файл GLB](Прокатный%20стан%20300.glb) содержит модель в метрах с именованными группами. Его также можно скачать кнопкой внутри просмотрщика.

## Границы точности

В модели 62 группы: нагревательная печь, ТРИО, шесть промежуточных и шесть чистовых клетей, термоупрочнение, ножницы, холодильник длиной 60 м, отделка и вспомогательные объекты.

Расположение основных узлов восстановлено по предоставленному плану. Высоты, корпуса, диаметры валков, детали приводов, фасады и штабели условные. Мелкие позиции, мостовые краны и коммуникации подробно не реконструированы. Модель предназначена для визуального обзора, не для изготовления и инженерных измерений.
